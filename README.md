# 💼 Personal Portfolio - Dejenie Derese Mitiku

Welcome to my personal portfolio website! This project is a responsive and modern one-page portfolio that showcases my skills, projects, contact information, and more.

---

## 📌 Description

This portfolio was created to highlight my professional background, skills, and projects in an interactive and user-friendly format. It includes sections for:

- Profile/Bio
- Skills
- Projects
- Contact
- Downloadable CV

---

## 🛠️ Technologies Used

- HTML5
- CSS3 (with Bootstrap 5)
- JavaScript
- Font Awesome (for icons)

---

## 📄 Features

- Clean and professional design
- Responsive layout for all devices
- Download button for my CV
- Project section with interactive cards

---

## 🚀 How to Use

1. Clone or download this repository.
2. Place your images (e.g., profile picture) and `dejenie-derese-cv.pdf` inside the `/assets/` folder.
3. Open `index.html` in a browser to view the portfolio.
4. Deploy to any static hosting platform (Vercel, GitHub Pages, Netlify, etc.)
